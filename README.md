# Реєстр виплат

Демо внутрішньої системи для обліку щомісячних виплат інвесторам.

- рахує нарахування (вклад × ставка ÷ 12) і звіряє з тим, що реально виплатили
- показує розбіжності, клік по розбіжності відкриває її в таблиці
- розбіжність можна позначити перевіреною з коментарем, позначки зберігаються в браузері
- фільтри, пошук, сортування, графік по місяцях
- імпорт і експорт CSV, приклад файлу є на сторінці

Формат CSV: `date,investor,product,amount,rate,paid`. Порожній `paid` значить що виплати ще не було.

Чистий HTML, CSS і JavaScript без фреймворків. Дані вигадані.
